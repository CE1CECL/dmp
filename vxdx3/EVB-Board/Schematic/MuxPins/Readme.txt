In Vortex86DX3, all the GP (IO) ports mux with different functions. For example in "DX3-Pin-Selection", you can see GP Port 0 can be GPIO, COM port or Full-Duplex SPI.  Only one function can be used at the same time, and it's defined by register/BIOS.   For detail setting, please 
-search the keyword "Internal Peripheral Feature Control" from datasheet.
-refer to Chapter 24.1 Multiple Function Pins Map and Configurations.
