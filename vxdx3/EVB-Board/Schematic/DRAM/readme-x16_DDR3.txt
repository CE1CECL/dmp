The Evaluation Board, DM 226B, use the x8 DDR3. If you want to use x16 DDR3, please refer  to DX3_DDR3x16.dsn in this folder. 

On DX3_DDR3x16.PDF you will see 
OPTION1: FIT *4 DDR3 ONE-DIE
This is the option for one-die x16 DDR3 x 4 pcs. 

OPTION2: FIT *2 DDR3 TWIN-DIE
This is the option for twin-die x16 DDR3 x 2 pcs 
DMP has tested the Micron MT41K512M16, it's 8Gb (twin-die 512Meg x16) DDR3. 
And please be noticed that BIOS should set to "2 RANK" and "No Address Mirror"  in flash strap setting (A9126_Flash_Strap_User_Guide_20150525_DMP.pdf) when use twin-die DDR3.
