The Gentoo system installation on EB333x.

 

“This is the procedure I did with Gentoo system on the VDX2 platform (EBOX-333x). For the Gentoo Linux system, you could follow the instruction as hand book guiding, to load the Live CD on the CD-ROM throught USB interface, and boot up from it to start the installation. Then to execute FDISK for storage as first step to start the installation with tips column, good luck!”

 

Following has few types for users as we are guiding with this instruction.

Platform Type:

l           Chapter 1, Basic System (without GUI)

l           Chapter 2, Desktop System (Procedure of GUI installation)

l           Chapter 3, NAS System

 

Chapter 1, Core System (without GUI).

Partition and System Configuration.

The disk partitions. The blue map as follow.

l           sda1 as /boot, 32MB, be sure to add boot flag on this partition!!

l           sda2 as /swap, depends on system.

l           sda3 as main partition for system, depends on system.

 

# fdisk /dev/sda

# mke2fs /dev/sda1

# mkswap /dev/sda2

# mke2fs –j –b 1024 /dev/sda3

# swapon /dev/sda2

 

1.          Mounting the partition for usage and correct the date of system.

# mount /dev/sda3 /mnt/gentoo

# mkdir /mnt/gentoo/boot

# mount /dev/sda1 /mnt/gentoo/boott

# date -s <now's time>

 

2.          Download the basic system and uncompress them for installation.

# cd /mnt/gentoo

# links http://www.gentoo.org/main/en/mirrors.xml

 

3.          Download these two files system needs from web and to uncompress them.

* stage3-*.tar.bz2

* portage-*.tar.bz2

# tar xvjpf stage3-*.tar.bz2

# tar xvjf /mnt/gentoo/portage-latest.tar.bz2 -C /mnt/gentoo/usr

 

4.          Setup the mirror server and setting.

# mirrorselect -i -o >> /mnt/gentoo/etc/make.conf

# cp -L /etc/resolv.conf /mnt/gentoo/etc/

 

5.          mounting the system and switch to root for application.

# mount -t proc none /mnt/gentoo/proc

# mount -o bind /dev /mnt/gentoo/dev

# chroot /mnt/gentoo /bin/bash

# env-update

# source /etc/profile

# export PS1="(chroot) $PS1"

 

6.          Update the list for latest packages

# emerge --sync

 

7.          To select target platform type

# eselect profile list

[1] 13.0 *

[2] 13.0/selinux

[3] 13.0/desktop

[4] 13.0/desktop/gnome

[5] 13.0/desktop/gnome/systemmd

[6] 13.0/kde

[7] 13.0/kde/systemmd

[8] 13.0/developer

[9] x86

[10] x86/selinux

[11] uclibc/x86

 

# eselect profile set <4>

 

# nano -w /etc/locale.gen

l           To select below locale

en_US ISO-8859-1

en_US.UTF-8 UTF-8

 

# cp /usr/share/zoneinfo/GMT /etc/localtime

 

Compiling a kernel!

 

# emerge gentoo-sources

# cd /usr/src/linux-4.0.5-gentoo

# cp /config-2013-05-29 ./.config

# make menuconfig

# make && make modules_install

# cp arch/x86/boot/bzImage /boot/kernel-3.3.8-gentoo

 

Config: ftp://vxdx2:gc301@ftp.dmp.com.tw/Gentoo/config-2013-05-29

 

Create the file system table!

 

# nano -w /etc/fstab

-------------------------------------------------------------------------

/dev/sda1   /boot          ext2    noatime              1 2

/dev/sda2   none          swap    sw                    0 0

/dev/sda3   /               ext3    noatime              0 1

/dev/cdrom  /mnt/cdrom   auto    noauto,user          0 0

-------------------------------------------------------------------------

 

# rc-update add net.eth0 default

# cd /etc/init.d

# ln -s net.lo net.eth1

# rc-update add net.eth1 default

 

# nano -w /etc/conf.d/hostname

# nano –w /etc/conf.d/net

-------------------------------------------------------------------------------------

HOSTNAME="dmp"

------------------------------------------------------------------------------------

# passwd

 

install some other package for system

# emerge syslog-ng

# rc-update add syslog-ng default

# emerge sys-apps/mlocate  // slocate?? 作用為何?

 

l           安裝dhcpcd IP工具

# emerge dhcpcd

 

Install the GRUB and setting!

 

# emerge -–noreplace sys-boot/grub:0

 

# nano -w /boot/grub/grub.conf

------------------------------------------------------------------------------------

default 0

timeout 30

splashimage=(hd0,0)/boot/grub/splash.xpm.gz

 

title Gentoo Linux 3.3.8

root (hd0,0)

kernel /boot/kernel-3.3.8-gentoo root=/dev/sda3 rw

 

title Gentoo Linux 3.3.8 (rescue)

root (hd0,0)

kernel /boot/kernel-3.3.8-gentoo root=/dev/sda3

init=/bin/bb

------------------------------------------------------------------------------------

 

# grep -v rootfs /proc/mounts > /etc/mtab

What’s the mtab mean and use for?

# grub-install --no-floppy /dev/sda

 

# exit

cdimage ~# cd

cdimage ~# umount /mnt/gentoo/boot /mnt/gentoo/dev /mnt/gentoo/proc /mnt/gentoo

cdimage ~# reboot
