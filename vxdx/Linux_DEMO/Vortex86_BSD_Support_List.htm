Vortex86 Series (DX/MX/MX+) BSD Support List

 

There is the BSD distributions support list:

FreeBSD:

For upcoming 8.2-RELEASE and 7.4-RELEASE do not include vte(4) since vte(4) was committed to tree in middle of preparation of 8.2-RELEASE and 7.4-RELEASE.

However, 8.2-RELEASE and 7.4-RELEASE users still can use vte(4) if he/she apply the patch at the following URL. http://people.freebsd.org/~yongari/vte/

See README.txt for more details on how to apply the patch.

 

OpenBSD:

The readied system image located ftp://129.128.5.191/pub/OpenBSD/snapshots/i386/install49.iso

You can download the image and install it on the Vortex86 platform directly.

OpenBSD source tree: http://marc.info/?l=openbsd-cvs&m=129506622317458&w=2

 

NetBSD:

there is now a working driver for the Ethernet part of the Vortex86:
