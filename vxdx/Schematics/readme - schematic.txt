Important Note.
From July 2009, the final D version of Vortex86DX ( the printing on this version is xxxx-D-PBGA) is ready for shipping.  If you start the design after July 2009, please using the latest D version, no need to consider about former version. 

When you are using the the DM-116A schematic, please be noticed the pin A7 and D14 will be switched in final D version of Vortex86DX. 
This schematic is for the former version of Vortex86DX. So when you do the design, please do remember to switch the pin A7 and pin D14
The A7 is DQS0+ and D14 is DQS1- on the final D version of Vortex86DX. 



------------- Reference Schematic of Vortex86DX-------------------------

DM-116A
The reference design mainly for Vortex86DX, this schematic support two DDR bank ( x16 bit DDR2 x 2 chips,  or x8 bit DDR2 x 4 chips), the PCB both support Vortex86DX & Vortex86SX design.


DMP Recommend Power Sequence v01
The document is the recommand power sequence for both Vortex86DX & Vortex86SX power design.
