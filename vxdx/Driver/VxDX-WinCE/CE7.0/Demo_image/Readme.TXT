
This image has XGI Z9s Display driver with LCD 32 bpp mode.
If your platform is not using XGI Z9s, it won't have any display.

BIOS setup before running demo image: (For AMIBIOS only)
1. Power on and press "Del" key into the BIOS setup.
2. Go to "Advanced" and "IDE configuration".
3. Set "IDE Operate Mode" to "Native mode".
4. Press "Esc" key back to "Advanced" memu.
5. Go to "USB Configuration".
6. Set "Legacy USB Support" to "Disabled".
7. Press "F10" to save the changes and exit.
8. Running demo image.
