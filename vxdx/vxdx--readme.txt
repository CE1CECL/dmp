Schematic:  DM77DX-V1.5
You will get the PDF format and OrCAD format of the schematic.  
In this schematic, it support both Vortex86SX and Vortex86DX, you can have both CPU with the same design, the difference are less than 10 pcs of resistors. For example, when you using Vortex86DX, some resistor much be populated, but with Vortex86SX, theose resistors should not be populated. 



DDR2 internal length. 
*VxDX_Ver_A_Trace length-0711, it's the DDR2 internal trace length of sample verison ( Version A) Vortex86DX.  This version is available from August 2008. 
*VxDX_Ver_B_Trace length-0711, it's the DDR2 internal trace length of production verison ( Version B) Vortex86DX.  This version is available from December 2008.
