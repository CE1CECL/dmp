2013/3/20
*BIOS
Vortex86EX mainly will use CoreBoot which is a open source BIOS, the CoreBoot BIOS is still under development, and plan to release the source in begining of May. 
At this moment, the evaluation board will come with temperatory BIOS, not full function, which is for customer to evaluation the performance of Vortex86EX. 

*Config Tool 
In Vortex86EX design, you can free choice and 80 pin for the digital I/O, please refer to "Vx86EX-SocCfgTool.pdf" to see how the config tool will be.  DMP will formally release it with CoreBoot source in the begining of May.
