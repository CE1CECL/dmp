Vortex86EX OS support list. 
- DOS
- Linux
- Windows CE 5.0 , CE 6.0  ( Compact 7.0 is under development)
- QNX 6.3.2 
- VxWorks 6.8 ( VxWorks 5.5 is under development) 
- Other RTOS should also supported if it has standard 486 BSP. 

You can download most of the drivers from http://www.dmp.com.tw/tech/vortex86dx/ , that website is for Vortex86DX and due to the core is the same between Vortex86DX and Vortex86EX, the driver is the same. 

If you can not find the driver you need from http://www.dmp.com.tw/tech/vortex86dx/, please contact soc@dmp.com.tw
